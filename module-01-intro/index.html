Module 1

Introduction to MCP 🤖🔗

Welcome to the MCP Protocol Course! This module covers the fundamentals of the Model Context Protocol — what it is, why it matters, and how it's transforming AI agent development.

📚 Module Overview

⏱️

Duration

~45 minutes (reading + exercises)

📈

Level

Beginner — No prior MCP knowledge required

📋

Prerequisites

Basic programming (JS/Python), AI/LLM familiarity

🎯

Outcome

Understand MCP concepts, components, and use cases

🎯 Learning Objectives

By the end of this module, you will:

  1. Explain what MCP is and why Anthropic created it
  2. Identify the three core MCP components (Host, Server, Client)
  3. Describe the three capability types (Tools, Resources, Prompts)
  4. Understand why MCP is called "USB-C for AI"
  5. Recognize real-world use cases and companies using MCP

📖 Lessons

1 ~10 min

The Problem MCP Solves

Before MCP, every AI agent needed custom integrations. Learn how MCP creates a standardized interface between AI agents and tools — like USB-C for AI.

2 ~15 min

MCP Core Concepts

Deep dive into the three components: Host (المضيف), Server (الخادم), and Client (العميل). Understand their roles and how they interact.

3 ~15 min

The Three Capabilities

Explore Tools (الأدوات), Resources (الموارد), and Prompts (القوالب). When to use each and how they differ.

4 ~5 min

Real-World Use Cases

See how companies like Block, Replit, Zapier, and Sourcegraph are using MCP in production today.

✏️ Exercises

Practice what you've learned with hands-on exercises:

  • Exercise 1.1: Identify the Components — Test your understanding of Host, Server, Client
  • Exercise 1.2: Tool vs Resource vs Prompt — Classify different capabilities
  • Exercise 1.3: Design Thinking — Design an MCP-powered system for an e-commerce business

📋 Summary

By the end of this module, you'll understand why MCP was created, how it works at a high level, and be ready to dive deeper into implementation in Module 2.
